# Adult Census Income Analysis

Data cleaning and exploratory analysis of the Adult Census Income dataset using Python.

## Dataset
The dataset used in this project is the Adult Census Income dataset obtained from Kaggle.

- EDA Report
- Jupyter Notebook
- Data Visualizations
- Project Presentation
